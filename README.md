
# 🎬 Netflix Movies and TV Shows – Exploratory Data Analysis

## 📌 Project Overview
This project explores the Netflix Movies and TV Shows dataset using Python. The goal is to analyze Netflix's content catalog, identify trends, and visualize insights through charts and a dashboard.

## 🎯 Objectives
- Analyze the distribution of Movies and TV Shows.
- Explore content release trends over the years.
- Identify the top countries contributing content.
- Analyze popular genres and content ratings.
- Study movie durations and TV show seasons.
- Visualize the data using an interactive dashboard.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Google Colab
- GitHub

## 📊 Project Features
- Data cleaning and preprocessing
- Missing value analysis
- Statistical analysis
- Exploratory Data Analysis (EDA)
- Interactive visualizations
- Netflix-inspired analytics dashboard

## 📁 Dataset
Dataset: Netflix Movies and TV Shows

Source: https://www.kaggle.com/datasets/shivamb/netflix-shows

## 🚀 How to Run
1. Download or clone this repository.
2. Open the `Netflix_EDA.ipynb` notebook in Google Colab or Jupyter Notebook.
3. Download the dataset from Kaggle.
4. Upload `netflix_titles.csv` when prompted.
5. Run the notebook cells in sequence.

## 📌 Conclusion
This project demonstrates how Python-based data analysis and visualization can be used to explore a real-world dataset and uncover useful insights about Netflix's content catalog.
